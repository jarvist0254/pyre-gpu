# Support and issues

For purchase, account, email verification or download help, contact
**support@jehorizon.com**. Include your purchase reference privately when useful;
it is a support reference, not an activation key.

Public issues are for reproducible application behavior and documentation.
Include the release version, Windows and Python versions, selected backend,
hardware model, expected behavior and observed result. A small synthetic script
is more useful than a private production workload.

Remove personal information and secrets from shared output. Do not post access
links, session cookies, provider tokens, payment details or proprietary application
files. Security reports belong in the private channel described in
[SECURITY.md](SECURITY.md).

Product availability, purchases and application downloads are handled at
[pyre.jehorizon.com](https://pyre.jehorizon.com/).
