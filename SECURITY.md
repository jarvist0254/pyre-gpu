# Reporting a security issue

Send a private report to **support@jehorizon.com** with the subject
“PyRe security report”. Include the affected release, a concise explanation and
safe reproduction steps. Describe the expected and observed access boundary.

Do not include live credentials, payment information or another person's data.
Avoid posting unpatched access-control details in public issues. If a test uses
an account or artifact, use one you own and identify any resulting side effects.

This repository contains documentation only. Purchase and application downloads
remain closed during final verification. Availability will be announced through
the [product website](https://pyre.jehorizon.com/).
